# 문지 스튜디오

문제 사진을 모아 A4 문제지로 만드는 한국어 웹 앱입니다. 외부 패키지 없이 브라우저에서 실행합니다.

## 실행

Windows에서는 Start-Munji.cmd를 실행하고 http://127.0.0.1:4173 으로 접속합니다. 같은 문지 서버가 이미 실행 중이면 확인 후 교체합니다. Node.js 20 이상에서 npm start로 서버를 직접 실행할 수도 있습니다. dist/index.html을 직접 열면 필기 제거 서버를 사용할 수 없고, 자동 저장도 브라우저 정책에 따라 제한될 수 있습니다.

## 주요 기능

- JPG·PNG·WEBP 여러 장 업로드와 드래그 앤드 드롭, 1~5점 난이도
- A4 1열/2열 자동 배치와 페이지 나눔, 드래그 순서 변경
- 여백, 열 간격, 구분선, 제목, 이름·날짜란
- 빈 공간/줄노트/모눈 풀이 공간과 개별 문제별 높이·사진 크기·새 페이지 시작
- 답 작성란과 별도의 정답지
- 사진 위에 여러 줄 텍스트 입력·드래그 이동·크기·색상·굵기·흰 배경, 자르기, 90도 회전, 흑백, 에코, 선명도, 그림자 보정, 색 필기 및 회색 연필 제거, 인쇄 글자 보호, 영역 선택·자동 제거·전후 비교·실행 취소, 전체/연필 전용 부분 지우개, 밝기·대비, 원본 복원과 보정 실행 취소
- PDF, Word DOCX, 한글 HWPX(베타), 고화질 PNG(여러 페이지는 ZIP) 내보내기
- 현재 브라우저 IndexedDB 자동 저장, 편집 가능한 .munji 프로젝트 저장/불러오기, 실행 취소·다시 실행

## 처리 방식과 제한

문제지 편집과 저장은 브라우저에서 처리하며, 필기 제거를 요청할 때는 해당 사진을 CamScanner로 전송합니다. 사진은 긴 변 최대 1800픽셀로 줄여 보관합니다. 파일당 30MB, 프로젝트당 100문제까지 지원합니다. 서버 계정 동기화는 포함하지 않습니다.

Word와 한글은 배치를 유지하기 위해 각 A4 페이지를 고해상도 이미지로 넣습니다. 문제 텍스트를 OCR로 변환하는 기능은 포함하지 않습니다. 기존 바이너리 HWP 형식은 지원하지 않으며 HWPX를 제공합니다. HWPX는 ZIP 무결성, XML 구문, 이미지 참조를 검사했지만 실제 한글 프로그램에서의 호환성은 확인하지 못했습니다.

필기 제거 버튼을 누르면 CamScanner 처리 결과가 편집 사진에 바로 반영됩니다. 후보 체크, 제거 미리보기, 별도 필기 적용 단계는 없습니다. 처리 뒤 ‘제거 전 / 제거 후’로 비교할 수 있으며, 제거 전을 보는 중에 저장하거나 다른 편집을 시작해도 제거 후 결과를 사용합니다. 실행 취소와 원본 복원을 지원합니다. 기본 적용 범위는 사진 전체이며, 영역 설정에서 선택 범위와 보호 영역을 지정할 수 있습니다. 부분 지우개의 기본 브러시도 드래그한 범위에 같은 필기 제거 기능을 적용합니다. 필기 제거에 사용하는 사진은 CamScanner로 전송되며, 외부 서비스 연결에 실패하면 편집 사진을 유지합니다. Start-Munji.cmd로 실행해야 필기 제거 서버를 사용할 수 있습니다.

기술 분석 및 한계: HANDWRITING_ANALYSIS.md. 실행한 합성 시험과 전후 이미지: qa/handwriting/index.html.

## 검증

app.js와 export.js의 구문 검사, 36가지 열·여백·간격·풀이 공간 조합에 각각 37문제를 넣어 누락·겹침·용지 범위 검사, PDF 재열기와 A4 규격 확인, DOCX·HWPX ZIP CRC와 XML 구조 검사, 필터 실행 및 프로젝트 검증을 수행했습니다. PNG·JPG·WEBP 사진의 보정창 열기, 필터, 실행 취소, 자르기, 회전, 적용, 다시 열기, 원본 복원도 검사합니다. 여러 줄 텍스트의 이동·스타일·취소·저장, 자동 필기 제거와 전후 비교, 비교 중 저장·도구 전환, 선택 범위와 보호 영역, 취소·실행 취소, 중복 요청 차단과 오류 시 사진 보존을 서비스 대역 응답으로 검사합니다. 실제 외부 서비스의 제거 품질은 이 검사의 대상에 포함되지 않습니다. qa/에 생성된 예시 출력물이 있습니다. verify.mjs는 제작 환경의 검증 패키지 경로를 사용하며 웹 앱 실행에는 필요하지 않습니다.

HWPX 구현 참고: [한컴 공식 HWPX 포맷 설명](https://tech.hancom.com/hwpxformat/) 및 [본문 구조](https://tech.hancom.com/python-hwpx-parsing-2/).
